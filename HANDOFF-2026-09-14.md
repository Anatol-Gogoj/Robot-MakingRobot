## 7. Traps

- **"Keep both sides" is not a conflict resolution.** The merge of `main` into #107 kept both sides of
  all six blocks. Effects: a duplicated JavaScript function where the *later* definition silently wins
  (the sequencer's E-STOP fault call disappeared), duplicated buttons, a README that said both "M500
  saves to EEPROM" and "M500 is unavailable". GitHub reported the branch as mergeable throughout.
  **Check any hand-resolved merge with**
  `git merge-tree --write-tree <parent1> <parent2>` **and** `git diff <that-tree> <merge-commit>`:
  the diff is exactly the human's resolution, and a diff that is only deleted `<<<<<<<`/`=======`/
  `>>>>>>>` lines means nothing was chosen. **[source]**
- **Squash merges hide merged branches.** `git branch --merged` does not list a branch whose commits
  reached `main` by squash (e.g. `claude/sequencer-homing-argon-uv-284459`), and `git branch -r
  --no-merged` lists 28 remote branches of which most are merged in substance. Use the PR state on
  GitHub, not ancestry, to decide what is outstanding.
- **`gh auth switch` also switches git's push credential** (the `gh auth git-credential` helper). A
  push that worked under one account can be refused under the other.
- **`direction: rtl` on a vertical `<input type=range>` flips which end is the minimum.** The Touch
  syringe slider used it and read "304 top / 0 btm" while the Controller read "0 up / 304 down". #107
  removed it so both sliders put B = 0 (nozzle up) at the top. **[source]**
- **`WARN:` still goes nowhere in the UI** (§5 item 5). Read the console.
- **Two PRs that touch adjacent lines of the same block both show `MERGEABLE`, then the second conflicts
  after the first lands.** #113 and #114 both edited the Stamp block; GitHub reported both clean against
  the pre-merge `main`. Merging #113 made #114 `CONFLICTING`. The fix is not `--force`: rebase the second
  branch onto the new `main`, resolve keeping *both* intents, re-run `node tests/run.mjs`, force-push,
  then merge. Merge the independent PRs first and leave same-block PRs for last. **[source]**
- **`gh pr edit` fails on this repo** with a GraphQL error about *Projects (classic) … projectCards*
  (a deprecated field `gh` still queries). Editing a PR title/body goes through the REST API instead:
  `gh api -X PATCH repos/Anatol-Gogoj/Robot-MakingRobot/pulls/<n> -f title=… -f body="$BODY"`. `gh pr
  create` and `gh pr merge --squash` work fine. **[source]**
- **No Node by default on this Linux dev box**, so `node tests/run.mjs` is "command not found" until you
  install one. There is no root: a portable build was unpacked to `~/.local` (`~/.local/bin` is already
  on `PATH`), so a bare `node` works now — but a fresh machine needs the same one-time step. **[source]**
